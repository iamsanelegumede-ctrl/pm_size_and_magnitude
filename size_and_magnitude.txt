1.1 - How many bytes are in a kilobyte? (2 marks)
1KB = 2^10
= 1024 bytes

1.2 - How many megabytes are required to express a single gigabyte? (2 marks)
1GB = 2^30
1MB = 26^20
So 2^30 / 2^20 = 2^10 = 1024 megabytes

1.3 - If memory in a computer is byte-addressable, meaning each address points to a single byte, how many addresses does 32 kilobytes of that memory have? (2 marks)
1KB = 2^10
32KB = 32 * 2^10 = 32768 addresses
